## About The Project

Over time I've had people interested in the kinds of feeds that I look at often in order to stay updated with the latest in technology news. Thanks to the aggregation of many other feed collections, and searching myself. I've created this repository as a collection of those feeds.

Since this uses standard OPML format this should be able to be imported into all kinds of RSS readers for your enjoyment. Personally I use the Cappy RSS reader on my android device.
